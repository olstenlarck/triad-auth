A small package used to verify the private registry.

## Install

Add the scope to `.npmrc`, so it will resolve ONLY `@tunnckocore/*` packages from there:

```ini
@tunnckocore:registry=https://npm.wgw.lol/
```

Install the package:

```bash
pnpm add @tunnckocore/calc
```
